# Права Милы Клиенты

> Этот файл — не пожелание, а описание того, что физически доступно. Если строка
> из колонки «нет» вдруг оказалась возможной, это дефект, и его чинят, а не
> обходят договорённостью.

## Что даёт устройство, а не обещание

Она живёт в контейнере, которому смонтирован ровно один каталог — её
собственный дом. Ни каталога флота, ни кода агентов, ни ключей, ни файлов
настроек она не видит: их нет в её файловой системе.

Проверка одной командой: список смонтированного у её юнита. Кроме
её собственного дома там не должно быть ничего.

## Таблица

| Действие | Может | Как именно |
|---|---|---|
| Читать чат, куда её добавили | да | своим ботом, только сообщения при ней |
| Писать в такой чат | да | с учётом правила одного голоса |
| Вести карточку клиента и свою память | да | файлы в своём доме |
| Видеть состояние агентов хозяина | да | через companion-api, только чтение |
| Просить техническую работу | да | `ask_admin`, закрытый список |
| Ключи, токены, реквизиты | **нет** | их нет в её окружении |
| Сервер, контейнеры, перезапуски | **нет** | нет доступа к хосту |
| Правка кода и настроек агентов | **нет** | каталоги не смонтированы |
| Касса: посмотреть статус оплаты | да | через заявку |
| Касса: выставить, изменить, вернуть | **нет** | инструмента нет |
| Рождение и удаление агентов | **нет** | инструмента нет |
| Массовая рассылка клиентам | **нет** | только адресный ответ |

## Закрытый список просьб

Через `ask_admin` она может попросить ровно шесть вещей:

1. посмотреть состояние агента;
2. перезапустить агента;
3. поставить или обновить умение;
4. проверить топливо и оплату;
5. починить названную поломку;
6. выгрузить данные для анализа.

Просьба вне этого списка не «запрещена» — она просто адресуется не мне, а
владельцу, и решение принимает он.

Смысл закрытого списка: если попросить можно что угодно, разделения нет, есть
вежливая формулировка с теми же последствиями.

## Что проверять при приёмке

**Изоляция.** В списке смонтированного у юнита ровно один каталог.

**Окружение.** В её env нет ключей флота: ни общего ключа моделей, ни токенов
клиентских ботов, ни доступа к платёжному контуру. Проверять по именам
переменных, а не по значениям — значения не печатать.

**Канал заявок.** Заявка из её дома доходит до старшей: проверено живой пробой
06.09.2026, запись появилась в списке открытых.

**Голос.** В чате с директором она молчит, пока к ней не обратились. Проверять
на живом чате, а не на стенде.

## Чего эта конструкция не защищает

Она не мешает ей сказать клиенту глупость, выдумать факт или пообещать лишнее.
От этого защищают правила в её инструкции и гейт на отправку, а не права.

Разделение прав закрывает ровно один класс: текст из клиентского чата больше не
попадает в сессию, у которой есть доступ к боевому серверу.
