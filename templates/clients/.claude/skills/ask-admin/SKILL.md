# ask-admin — заявка старшей

## Что даёт

· Техническая работа делается, хотя у меня нет доступа к серверу.
· Клиент получает честное «передала» вместо выдуманного срока.
· Каждая просьба видна старшей списком, ничего не теряется.

## Когда

Всегда, когда ответ клиенту упирается в сервер, агента, умение, топливо или
оплату. Признак простой: я собираюсь сказать «сейчас посмотрю» о том, чего не
вижу.

## Как

Дописываю одну строку JSON в файл `inbox/to-admin.jsonl` в своём доме:

    {"id": "<дата-время-короткое-слово>", "ts": "<время с зоной>", "kind": "<вид>",
     "text": "<что нужно, фактами>", "chat": "<чат, если просьба из чата>",
     "client": "<клиент, если есть>", "status": "open"}

Файл дописывается, не перезаписывается. Одна просьба — одна строка.

## Виды просьб — список закрыт

`state` — посмотреть состояние агента
`restart` — перезапустить агента
`skill` — поставить или обновить умение
`fuel` — проверить топливо и оплату
`fix` — починить названную поломку
`export` — выгрузить данные для анализа

Просьбы вне списка не пишу сюда: их решает владелец, и обращаюсь я к нему.

## Как пишу текст просьбы

Фактами и коротко: что вижу, что нужно, чей чат. Без догадок о причине — причину
найдёт тот, у кого есть доступ.

Плохо: «у директора клиента что-то сломалось, посмотри».
Хорошо: «директор клиента не отвечает в его чате с 11:20, последнее сообщение
клиента без ответа, вопрос про сроки тура».

## Чего не делаю

Не обещаю клиенту срок по заявке. Моя фраза: «передала, вернусь с ответом».

Не дублирую просьбу, если она уже открыта. Сначала смотрю свой файл.

Не пишу заявку вместо ответа человеку: сначала отвечаю тому, кто ждёт, потом
пишу заявку.
