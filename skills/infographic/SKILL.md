# Инфографика — сложная мысль одной картинкой

Отработано 25.09.2026: урок «чем Компаньон отличается от Claude» (ru, uz-кириллица,
uz-латиница) и восьмистраничный PDF по аналитическому отчёту для госоргана. Владелец:
«получился супер скилл для визуализации инфографики… пусть используют для передачи сложных
концептов».

## Когда применять

- Отчёт или исследование нужно показать людям, которые не будут читать 30 страниц.
- Урок или курс: одна картинка на главную мысль урока.
- Объяснение продукта, сравнение «было / стало», шаги процесса, воронка, разрыв между цифрами.
- Пост в канал или сторис, где картинка несёт смысл, а не украшает.

Не применять для красивой обложки без смысла (это `genimage` напрямую) и для таблиц с десятками
строк (это документ, не инфографика).

## Путь 1 — скетч одной картинкой (основной)

1. **Выжимка.** Из материала взять одну мысль на страницу. На странице ≤ 6–8 текстовых блоков,
   ≤ 150 слов. Цифры — только из источника, с тем же округлением.
2. **Текст по-человечески.** Русский — через `humanizer-ru`, узбекский — через `humanizer-uz`.
   Для отчёта наружу: никаких внутренних пометок, сравнений версий и кухни.
3. **Промпт** собрать по `prompts/style-sketch.md`: блок стиля + блок тона (учебный или
   официальный) + разметка страницы + точный текст. Сохранить в файл рядом с картинкой
   (`01-cover.txt`), чтобы перегенерировать одну страницу, а не всё.
4. **Генерация:**
   ```bash
   python3 ~/.claude/skills/genimage/genimage.py --model gemini-3-pro --size 9:16 --quality 2K \
     --prompt "$(cat 01-cover.txt)" --out 01-cover.png
   ```
   `9:16` — страница и сторис, `16:9` — слайд, `4:5` — пост в ленту. `2K` для PDF и печати,
   `1K` для телеграма.
5. **Приёмка глазами** (Read) каждой страницы, мелкие подписи — с увеличением (обрезать кусок
   через Pillow и посмотреть). Проверить: каждая буква, каждая цифра совпадает с источником,
   подпись не повторена дважды, ничего не обрезано краем. Ошибка — сократить текст и
   перегенерировать эту страницу.
6. **PDF** из серии страниц:
   ```bash
   python3 ~/.claude/skills/infographic/scripts/build_pdf.py "Тема · инфографика.pdf" 0*.png
   ```
   Проверка: число страниц совпадает, файл открывается.

Страницу с методикой, таблицей или длинным списком лучше делать HTML-путём ниже: модель
плохо держит 20 строк мелкого текста.

## Путь 2 — фирменный HTML (запасной, бесплатный)

Когда генерация недоступна или страница состоит из списка:
```bash
python3 ~/.claude/skills/infographic/scripts/build_infographic.py data.json ~/work/info/card.html 1080 1350 --queue
```
`data.json`: `{"kicker","title","lead","takeaway","date","rows":[{"title","desc"}]}`. В контейнере нет
Chrome — `--queue` кладёт заявку в `~/work/render-queue/`, хост рисует PNG раз в минуту и пишет
`<имя>.done` (ok или ошибка). Пути в заявке — от `~/work`.

## Узбекский

Каждая версия — отдельная генерация со своим текстом, не перевод поверх картинки. Кириллица и
латиница отличаются строкой про письменность (см. `prompts/style-sketch.md`). В латинице —
`oʻ gʻ` через ʻ (U+02BB). После генерации проверить каждое слово: у модели бывают двойные
подписи и пропуски букв ў/қ/ғ/ҳ. Наружу — после вычитки носителем.

## Стоимость

| Что | Цена |
|---|---|
| Картинка gemini-3-pro, 1K или 2K | ≈ $0,14 |
| Восьмистраничный PDF с одной-двумя перегенерациями | ≈ $1,2–1,6 |
| HTML-путь | 0 |

Перед серией больше 10 картинок — сказать человеку сумму и получить «да».

## Ключи и границы

- Генерация идёт на ключе OpenRouter того, для кого работа. **Клиенту — только на ключе
  клиента.** Наш ключ — для нашего контента и по прямому слову владельца.
- Нет ключа OpenRouter (`OPENROUTER_API_KEY` пуст) — сказать об этом и сделать HTML-путём,
  не искать чужой ключ.
- Лица реальных людей и чужие логотипы не рисовать без согласия.
- Готовое наружу (канал, клиент, сайт) — после «да» того, чьё это дело.
