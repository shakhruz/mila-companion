## 1. Страница входа говорит только по-русски

**Кто заметил:** владелец, 06.09.2026, сразу после активации подписки.
**Его слова:** страница удобная и красивая, но «mila-companion у нас для всего
мира, UI должен быть англоязычным по умолчанию с возможностью переключить на
русский и узбекский».

**Почему это важнее, чем кажется.** Проект открыт наружу, README английский, а
первая страница, которую видит человек при подключении, — русская. Для нас
незаметно, для любого не-русскоязычного это стена на первом шаге, и до второго
шага он не дойдёт.

**Что делать.** Английский по умолчанию. Русский и узбекский переключением,
выбор запоминается. Определение по языку браузера, чтобы русскоязычному не
приходилось переключать вручную.

**Где:** страница входа Компаньона, тексты вынести из разметки в отдельный
словарь — иначе третий язык добавится копированием файла.

**Осторожно.** Страница боевая: через неё заходит владелец и будут заходить
клиенты. Правки не посреди запуска, и обязательно живая проба входа после — не
чтением кода, а настоящим входом.

**Приёмка.** Открыть страницу с браузером на английском — интерфейс английский;
переключить на русский — переключился и запомнился; вход по одноразовой ссылке
проходит на всех трёх языках.

## 2. Ветка systemd у часового сбора не проверена на живом сервере

**Кто заметил:** сама, 10.09.2026, сдавая учёт разговоров и трат.

Установщик ставит часовой сбор ходов двумя способами: launchd на Маке —
проверен живьём (таймер стоит, отработал за 14 с), systemd на сервере —
написан по образцу рабочего юнита приёмника из `deploy/bootstrap.sh` и вживую
НЕ запускался ни разу.

**Что проверить при ближайшей раскатке Компаньона на сервер:**
`systemctl --user list-timers mila-turns-collect` показывает следующий запуск ·
после срабатывания обновился `~/.claude/analytics/turns-collect-last.json` ·
`mila doctor` говорит 🟢 по обеим строкам таймера · юнит переживает
перезагрузку (`loginctl enable-linger` для пользователя, иначе таймер
пользователя не стартует без сессии).

**Почему записано:** пока об этом знают двое, это не долг, а память. Через
неделю Компаньон уедет на сервер, таймер молча не запустится, и учёт будет
выглядеть как спокойный день.
